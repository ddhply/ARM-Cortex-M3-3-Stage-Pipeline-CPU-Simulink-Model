**【Simulink】ARM7内核三级流水线CPU仿真模型**

本仿真平台能够实现对STM32的C语言工程文件的运行，自然需要包括数据处理、分支跳跃、访存、位处理、标志位、乘除法等基础功能。至于其他系统级功能，比如时钟初始化、中断服务函数等，都是基于SRAM地址映射后的结果，在本仿真平台都将他们假设为只是对内存的访问。本设计只考虑流水线行为。
本次的设计目标是用Simulink工具搭建简单的三级流水线测试平台，最终实现STM32的C语言程序功能，并希望能够借此在搭建的过程中充分理解分支目标转发 (Branch Target Forwarding)、MR（Memory Replay）状态机、多周期指令、数据冒险等概念。

*******************************************************************************************************
使用说明：
            1.将所需执行的C语言工程文件输出转为hex文件，格式如下，每行只有一个字，不包含地址。
                如: 20000530
                    080001CD
                    080001D1
                    080001D3
                    080001D5
                    080001D7
                    ...
            2.在Matlab中打开../_3stages_/Three_Stages.slx
            3.运行../_3stages_/test.m，可在文件中修改运行时间
*******************************************************************************************************
